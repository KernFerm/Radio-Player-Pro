# Radio Player Pro

Version: 0.0.85

Radio Player Pro is a Windows desktop app for browsing, searching, and listening to internet radio stations.

## What You Can Do

- Search for stations by name, country, language, or music type
- Listen to live internet radio from your desktop
- Save favorite stations
- Return to your last played station
- Use the mini player for a smaller listening window
- Keep the app available from the Windows tray while it is running
- Open Help and support from inside the app

## Install

1. Download the Windows setup EXE for the latest version.
2. If you already have Radio Player Pro installed, uninstall the old version first.
3. Double-click the setup EXE.
4. Accept the license.
5. Choose the install folder.
6. Finish setup.
7. Open Radio Player Pro from the Start menu or the install folder.

## Update

1. Close Radio Player Pro.
2. Uninstall the old version.
3. Run the new `v0.0.85` setup EXE.
4. Open the app normally.

Your favorites and app settings are saved in your Windows user profile and should still be available after updating.

## Basic Use

1. Open Radio Player Pro.
2. Search for a station.
3. Select a station to play it.
4. Save favorites for stations you want to use again.
5. Use the mini player or tray icon when you want the app out of the way.

## Notes

- Radio streams come from public stations and directories.
- Some stations may be offline or unavailable at times.
- The tray icon may appear in the hidden tray area depending on your Windows settings.

## Support

Use the Help menu inside Radio Player Pro for app information and support links.
