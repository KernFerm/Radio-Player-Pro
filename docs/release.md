# Radio Player Pro v1.0.5

Radio Player Pro is a Windows app for listening to internet radio stations from your desktop. You can search for stations, save favorites, and keep playback handy with the mini player and tray icon.

## Before You Install

- If you already have an older version installed, uninstall it first.
- Close Radio Player Pro before starting the installer.
- If Windows asks whether you want to allow the installer to make changes, choose Yes.

## How To Install

1. Download the Windows setup file for `v1.0.5`.
2. Double-click the setup EXE.
3. Read and accept the license.
4. Choose where you want Radio Player Pro installed.
5. Finish the installer.
6. Open Radio Player Pro from the Start menu or the install folder.

## First Setup

1. Open Radio Player Pro.
2. Use Search to find a station by name, country, language, or music type.
3. Select a station to start listening.
4. Use the heart/favorite option to save stations you want to find again.
5. Adjust the volume inside the app.
6. Use the mini player when you want a smaller listening window.

## Using The App

- Search: Find stations by station name, tag, country, or language.
- Favorites: Save stations you listen to often.
- Last station: The app remembers your last played station.
- Mini player: Keep simple playback controls on screen.
- Tray icon: Keep Radio Player Pro available while it is running.
- Help: Open the Help menu inside the app for support and app information.

## Updating From An Older Version

1. Close Radio Player Pro.
2. Uninstall the old version from Windows Settings or Control Panel.
3. Install `v1.0.5` using the new setup EXE.
4. Open the app normally.

Your saved favorites and app settings are kept in your Windows user profile.

## If Windows Shows A Warning

Windows may show a safety prompt for downloaded apps. Make sure the file is the Radio Player Pro `v1.0.5` setup EXE you intended to download, then choose the option to run it.

## Need Help?

Open the Help menu inside Radio Player Pro. You can view app information and use the support link from there.
